Сегодня 26 ноября — неделя уложила гигантов на лопатки: вчера Microsoft объявлял Code Red после исторического сбоя, сегодня GitHub второй день ищет причину деградации по всем продуктам. Дальше — инцидент в backend у 1Password, где хранилища паролей целы, и альфа Ladybird: до независимого браузера впервые можно дотянуться руками.

### GitHub второй день ищет причину деградации

Сюжет продолжается вчерашней линией: сразу после Code Red в Microsoft деградировать начала вся платформа GitHub — репозитории, Actions, страницы отвечают через раз. Статус-страница второй день ведёт расследование «degraded experiences across GitHub products», обсуждение на Hacker News не гаснет. Паттерн узнаваемый: сначала падает общая шина, потом посыпались зависимые сервисы. Ирония недели: вчерашний мем «у кого сбой — тот объявляет Code Red» обгоняет сам себя — ритейл-проверка отказоустойчивости у всех сразу. Что забирать в свой прод из этого: изоляция отказов — не академическая история, а то, что вы тоже можете поймать на своей архитектуре.

### 1Password: инцидент в backend, хранилища целы

Менеджер паролей 1Password отчитался об инциденте в своих серверных системах — тот самый жанр новости, от которого у любого пользователя холодеет спина. Ключевое из апдейта: пользовательские хранилища не затронуты и содержимое остаётся защищённым; речь про backend-инфраструктуру компании. Компания публиковала обновления по мере расследования — правильный жанр для инцидент-репорта: скажи быстро, скажи честно, продолжай уточнять. Вопрос, который остаётся открытым: как вообще стало возможным касание backend у продукта, чей основной продукт — безопасность. Проверьте у себя: где у вас границы доверия между «секретами пользователей» и служебной инфраструктурой.

### Ladybird открыл альфу: до независимого браузера можно дотянуться

Ladybird — браузер с собственным движком, без Chromium — выложил первую альфу: сборки для macOS и Linux. Формулировка команды честная: «пока не готов заменить повседневный браузер» — ставьте, ломайте, сообщайте о багах. С 2018 года проект вырос из просмотрщика документации SerenityOS в единственный по-настоящему независимый браузер не от корпорации: свой движок, свой рендер, никакой совместимости с Chromium. Почему это важно на практике: монокультура движков — это когда одна ошибка в Chromium одновременно и у вас, и у всех. Альфа — не повод менять прод-браузер; повод — посмотреть своими глазами, как выглядит альтернатива, и поддержать проект тестированием.
