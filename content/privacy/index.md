### Кто обрабатывает данные

Сайт kgoryachev.ru и связанные с ним каналы публикации ведёт Константин Горячев (далее — автор). Контакт для вопросов о данных: kevin.glare@gmail.com.

### Сайт

Сайт собирает обезличенную статистику посещений через Яндекс Метрику: страницы, источники переходов, устройство и браузер. Эта статистика не содержит персональных данных и используется только для понимания аудитории блога. Комментарии и формы обратной связи на сайте отсутствуют.

### Telegram-канал

Автор публикует дайджесты в публичный Telegram-канал через собственного бота. Бот не собирает и не хранит данные подписчиков: он только отправляет сообщения в канал. Подписка на канал видна Telegram так же, как и при любом другом канале.

### YouTube и Instagram

Публикация видео-дайджестов выполняется авторским скриптом через официальные API (YouTube Data API, Instagram Graph API). Скрипт авторизован только на собственных аккаунтах автора и не обращается к данным других пользователей. Загружаемый контент — материалы самого автора. Обработка данных на стороне YouTube подчиняется [Политике конфиденциальности Google](https://policies.google.com/privacy?hl=ru); использование YouTube Data API соответствует [Правилам для разработчиков YouTube](https://developer.youtube.com/terms/developer-policies).

### Удаление данных

Отзыв доступа авторского скрипта к YouTube-аккаунту выполняется в настройках Google-аккаунта (Безопасность → Приложения с доступом к аккаунту) — после отзыва сохранённый токен перестаёт действовать, все данные, к которым скрипт имел доступ, остаются только у Google по его политикам. Персональных данных посетителей на серверах автора не хранится, поэтому удалять у автора нечего. Статистика Яндекс Метрики хранится и удаляется по правилам самого сервиса.

### Передача третьим лицам

Данные посетителей не передаются третьим лицам, кроме описанной анонимной статистики (Яндекс Метрика) и стандартной телеметрии платформ (YouTube, Instagram, Telegram), обрабатываемых этими сервисами по их собственным политикам конфиденциальности.
